# 00 — DEFINITION OF DONE

Uma funcionalidade só é concluída quando possui código, contrato, validação, autorização, tratamento de erros, testes, observabilidade e documentação.

Checklist:
- [ ] implementação
- [ ] API
- [ ] banco
- [ ] autorização
- [ ] estados de UI
- [ ] testes unitários
- [ ] integração
- [ ] observabilidade
- [ ] segurança
- [ ] documentação
- [ ] validação final
