# 00 — VISÃO GERAL

## Objetivo
Documento central do VIAPAY: escopo, princípios, módulos, arquitetura e critérios de conclusão.

## Produto
Plataforma de pagamentos API-first para merchants e operações financeiras, abrangendo pagamentos, PIX, transações, clientes, settlement, conciliação, ledger, integrações, webhooks, administração e developer portal.

## Princípios
- Clean Architecture
- DDD
- SOLID
- API First
- baixo acoplamento
- idempotência
- observabilidade
- segurança por padrão
- testes automatizados
- documentação como fonte de verdade

## Regra
O estado real deve sempre ser determinado por auditoria do código. Documentação não deve declarar como implementado aquilo que não foi validado.
