# FX Sandbox

O FX Sandbox simula:

- quotes;
- rates;
- fees;
- quote locking;
- conversion;
- failure;
- expiration.

Exemplo:

BRL 109.00
    |
    v
FX Quote
    |
    v
USDC 19.00

Os valores são fictícios.

Não utilizar taxas de mercado reais para representar liquidação.

Produção deverá integrar um FxProviderPort.
