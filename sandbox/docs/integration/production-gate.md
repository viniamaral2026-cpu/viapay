# Production Access Gate

Nenhum desenvolvedor deve receber credenciais de produção
automaticamente.

Critérios:

1. Sandbox integration completed
2. API contract validated
3. Webhook validation implemented
4. Idempotency implemented
5. Authentication validated
6. Security review
7. Production application approved
8. Merchant/institution onboarding completed
9. Compliance requirements completed where applicable
10. Production credentials issued

Estados:

SANDBOX

CERTIFICATION

PENDING_APPROVAL

APPROVED

PRODUCTION_ENABLED

SUSPENDED

REVOKED
